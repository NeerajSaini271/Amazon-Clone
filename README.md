## Overview
This project is a front-end replica of the Amazon homepage, built using **HTML** and **CSS**. It features a responsive layout, including a navigation bar, product listings, and a footer. The design emphasizes mobile-first responsiveness and clean UI structure.

## Features
- Responsive layout for desktop and mobile devices
- Navigation bar with logo and search functionality
- Product listings with hover effects
- Footer with links to various sections
- Mobile-first design for a seamless experience on all devices

## Tech Stack
- HTML5
- CSS3 (Flexbox and Grid)

## Live Demo
Experience the live demo here: [https://amazon-clone-bm.netlify.app/](https://amazon-clone-bm.netlify.app/)

## Getting Started
1. Clone or download the repository.
2. Open `index.html` in your browser to run the project locally.
3. Optional: Use a local static server (e.g., `npx http-server`) to simulate hosting.

## Responsive Design Notes
- Layout uses CSS Flexbox and Grid for main sections
- Breakpoints implemented for tablets and mobile screens
- Images and product cards scale fluidly (`max-width: 100%` and `height: auto`)
- Text sizes use relative units (`rem`) for better readability on smaller devices
